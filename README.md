# Melon Portal

An open-source Laravel app for selling software directly: support tickets and license keys in one place.

I'm building it in public for my own plugin business, [WPMelon](https://wpmelon.com). The goal is to move WPMelon's support and licensing onto it once it works end to end.

## Status

**Nothing to install yet.** This repo has a README, a license and a few notes. The Laravel app starts in the next phase. Follow along below if you want to see it grow.

## What it is meant to cover

Planned, not built:

- **Helpdesk:** customers open tickets, I answer them, history stays in one place.
- **Licensing:** license keys for plugins, with activation checks from the plugin side.

The scope will get more precise as I build. Each bigger choice gets a short note in [`docs/decisions`](docs/decisions).

## Stack

Laravel, Livewire, MySQL.
